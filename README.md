Event Registration Website

Created a beginner-level HTML web development project.

About the Project:
This project is a simple and user-friendly Event Registration Website developed using HTML. It provides information about an event and allows interested participants to register by filling out an online registration form.
The website consists of two interconnected HTML pages that provide a smooth navigation experience for users.

The form.html and details.html is written on notepad. The images are saved in PNG file type.

PROJECT STRUCTURE:
form.html – Main event registration page.
details.html – Contains additional event information and registration details.
Image files – Used for the visual presentation of the website.

The objective of this project is to create a basic event registration website using HTML and understand how multiple web pages can be connected through hyperlinks.
